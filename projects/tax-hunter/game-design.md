# 1. ゲーム概要

## 1.1 タイトル(仮)

**『TAX HUNTER 〜失われた税典と七つの大陸〜』**(略称: タクハン)

## 1.2 ジャンル

**知識狩猟オープンフィールドRPG**
(収集育成 × 狩猟アクション × 法廷推理 × 生活シミュレーション)

## 1.3 一行コンセプト

> **「知れば知るほど強くなる」を極限まで面白くした、世界初の"知識が武器"のAAA級RPG。**

## 1.4 ゲームの正体(社内限定・プレイヤーには開示しない設計思想)

本作は「遊んでいるだけで税理士試験レベルの知識体系(簿記・FP・所得税・法人税・消費税・相続税・固定資産税・住民税・社会保険・会社設立・インボイス・電子帳簿保存法)が身につく」ことを裏ゴールとする。
ただし**プレイヤー体験上は一切「教育」を感じさせない**。学習理論(分散学習・検索練習・精緻化・インターリービング)は、すべて以下のようにゲームメカニクスへ**翻訳**して実装する。

| 学習科学の原理 | ゲームメカニクスへの翻訳 |
|---|---|
| 検索練習(思い出すほど定着) | バトルの「弱点看破」= 知識を思い出して撃つ |
| 分散学習(間隔反復/SRS) | 倒したモンスターが忘却曲線に合わせて「リポップ」し、再討伐で希少素材を落とす |
| 精緻化(理由の説明) | 推理パートで「なぜ矛盾か」を選んで論破する |
| インターリービング(混合練習) | 複数税目の敵が混成で出現する「混成の魔群」 |
| 誤答からの学習 | 敗北時に敵図鑑へ「弱点ヒント」が追記される(敗北=図鑑が育つ) |
| 転移(現実応用) | AI税理士が現実の悩みをクエスト化する |

## 1.5 ターゲット

1. **敵に「正解」を撃ち込むバトル** — 知識がそのまま火力になる、世界初の狩猟体験
2. **税図鑑コンプリート** — 制度・判例・用語・モンスターを全て集める収集の快感

4. **毎年の税制改正 = 毎年の大型無料アップデート** — 現実世界がコンテンツを供給し続ける

# 2. コアループ

## 2.1 30秒ループ(バトル内)

```
敵の「問い」が来る → 3〜4択 or スワイプ判定(3秒) → 正解 → 弱点看破エフェクト+コンボ加算
→ 攻撃入力(タップ連打+スワイプ回避) → ダメージ+ドロップ予告演出 → 次の問い
```

**設計意図**: 「問いに答える」を"敵の攻撃モーションを見切る"のと同じ**反射的快感**として設計する。正解音・ヒットストップ・コンボ表示のジューシーさに全予算を投じる。

## 2.2 5分ループ(1狩猟)

```
クエスト受注 → フィールド探索(採取=領収書・証憑集め) → モンスター発見 → バトル
→ 討伐 → レアドロップ判定(ディアブロ型) → 図鑑更新 → 素材で装備クラフト
```

## 2.3 1日ループ(3〜15分)

```
ログイン → 税界ニュース(法改正を世界の異変として演出) → デイリー討伐3件
→ リポップした「忘却の魔物」再討伐(=間隔反復) → NPC1人と交流 → 明日の狩猟予約
```

## 2.4 1週間ループ

```
ウィークリーボス(税務署ダンジョン) → 推理事件1件 → ギルド協力狩猟
→ ハンターランク試験(昇格試験=実は単元テスト) → 週間報酬
```

## 2.5 シーズンループ(年4回+年1大型)

```
四半期シーズンイベント(確定申告祭・年末調整祭・納期の特例祭 等)
→ 年1回「税制改正」大型アップデート = 新大陸・新魔物・新装備
```

## 2.6 ループを回す3つのエンジン

1. **未完の図鑑**(ツァイガルニク効果): 常に「あと3体」「あと1ページ」が見える
2. **リポップ予告**(アポイントメント): 「明日の朝、レア個体が再出現します」
3. **人間関係の続き**(物語的牽引): NPCの悩みが「次に会う理由」を作る

# 3. 世界観

## 3.1 舞台: 大陸世界「フィスカリア」

かつてフィスカリアは、**大税典(グランド・コデックス)**と呼ばれる叡智の書によって、富が公正に巡る豊かな世界だった。税は「共同体の血液」であり、道路も学び舎も癒し院も、皆で支え合う仕組みが機能していた。

しかし**「忘却の獣ゼイム」**が大税典を喰らい、その知識を**無数の魔物「タックスビースト」**として世界にばら撒いた。

- 人々は税の仕組みを忘れ、正しい申告ができなくなった
- 国庫は枯渇し、橋は落ち、学び舎は閉じ、癒し院は薬を失った
- 魔物は人々の「無知」と「不安」を喰って肥え太る

## 3.2 主人公: 税務ハンター

主人公は**王立徴収庁の残党が組織した「税務ハンターギルド」**の新米ハンター。
魔物を狩ると、魔物が体内に溜め込んだ**「知識の欠片(ナレッジシャード)」**がドロップする。欠片を集めて大税典を復元し、街に「制度」を返すことで、世界が目に見えて復興していく。

**世界の復興 = プレイヤーの知識量** という同期構造が本作の背骨である。
(例: 医療費控除の知識を取り戻すと、廃墟だった癒し院に灯りがともり、NPCが治療を受けられるようになる)

## 3.3 トーン&マナー

- ビジュアル: 温かみのあるハイファンタジー。手描き風トゥーンシェード
- 音楽: フルオーケストラ+民族楽器。大陸ごとにテーマ曲
- 税の描写は**「悪」ではなく「巡り」**として描く。敵は税そのものではなく「税を歪める無知と欺瞞」

## 3.4 キーワード辞書(オリジナル用語)

| 用語 | 意味 |
|---|---|
| 大税典(グランド・コデックス) | 世界の税知識の総体。全13巻(=学習カリキュラム13分野) |
| ナレッジシャード | 魔物が落とす知識の欠片。装備・図鑑・復興の素材 |
| タックスビースト | 歪んだ税知識が実体化した魔物 |
| 徴憑(ちょうひょう) | 領収書・請求書・帳簿など証拠アイテムの総称 |
| 濁り(にごり) | 世界に広がる無知の霧。図鑑完成度に応じて晴れる |
| ハンターランク | G→F→E→D→C→B→A→S→SS(SS=税理士試験合格相当) |

# 4. ストーリー

## 4.1 全体構造(3部構成・全13章)

**第1部「目覚めの草原」(1〜4章)** — 生活者の税
主人公は記憶を失った状態で草原の村に流れ着く。村の収穫祭で「実りの一割を巡る争い」に遭遇し、初めてタックスビーストと戦う。所得・簿記・消費の基礎を取り戻しながら、相棒AI妖精**「レシー」**(レシート精霊)と出会う。

**第2部「巡りの大陸」(5〜9章)** — 事業と資産の税
各大陸の「税柱(ぜいちゅう)」が魔物に占拠されている。法人・相続・固定資産・住民税の巻を復元しながら、忘却の獣ゼイムの正体に迫る。中盤の大どんでん返し: **ゼイムはかつて民を守るために「複雑になりすぎた税制」を憎んだ元・大税官**だった。

**第3部「大税典の真実」(10〜13章)** — 制度の設計者へ
国際税務・インボイス・電子帳簿・未来税制の巻を巡り、最終決戦へ。ラスボス戦は「ゼイムを倒す」のではなく、**歪んだ制度知識を一つずつ論破し、正しい形に"申告し直す"**ことで浄化するマルチフェーズ戦。エンディングで主人公は「大税官」として、プレイヤー自身の言葉で世界に税の意味を宣言する。

## 5.2 各フィールドの標準構成

- **大型オープンエリア**(徒歩10分スケール): 採取ポイント(徴憑・素材)、野生モンスター、環境パズル
- **街1**: クエストハブ、ショップ、ギルド支部、NPC生活圏
- **村1〜2**: サブクエスト、隠しNPC
- **ダンジョン2〜3**: 中ボス配置。地形ギミックが「その税目の計算構造」を体で覚えさせる
- **税務署(ボス砦)**: フィールド最深部。占拠された税務署を解放するとファストトラベル解禁+街が復興
- **隠しエリア**: 図鑑完成度・NPC信頼度・特定装備で開放(例: 草原の「損益通算の地下水脈」)

## 5.3 探索の自由度

- 序盤から全大陸へ物理的には行ける(BotW型)。ただし敵の問いの難度が高く「知識の壁」が実質的なレベルデザインになる
- 「濁り」の霧は図鑑完成度で晴れ、ミニマップが精細化する
- 崖登り・パラセール等の派手な移動は入れず、**「税紋グライド」**(正解コンボで貯まるエネルギーで滑空)というオリジナル移動を採用

# 6. モンスター設計

## 6.1 設計原則

- **1税目=1系統100種以上**。「種族×属性×ランク」のマトリクスで量産しつつ、各個体に固有の知識テーマを1つだけ持たせる(1モンスター=1論点)
- モンスターの**見た目・行動・弱点が、税知識の構造をそのまま可視化**する

## 6.2 種族カタログ(抜粋)

| 種族 | 税目 | デザインと知識の対応 |
|---|---|---|
| インカム・スライム系 | 所得税 | 10色に分裂するスライム。色=所得10分類。「給与色」と「事業色」を見分けて正しい器で受けないと吸収されない |
| レシート・ウィスプ系 | 経費 | 領収書の群れが妖精化。本物(事業関連)と偽物(家事費)が混在し、偽物を撃つと反撃 |
| コンサンプ・キャメル系 | 消費税 | 砂漠の隊商駱駝。背中の荷(仕入)と売り物の差額にしか攻撃が通らない(仕入税額控除の体感) |
| コーポレート・ドラゴン系 | 法人税 | 決算期ドラゴン。事業年度ゲージが満ちる瞬間の「申告ブレス」を正しい期限知識でガードする |
| レジデント・ウルフ系 | 住民税 | 1月1日の月夜にだけ群れる狼。前年に倒した敵の数で今年の群れの規模が決まる |
| プロパティ・タイタン系 | 固定資産税 | 動かない巨人。評価額のコアが1.4%の周期で明滅し、そこだけ攻撃が通る |
| インヘリト・リッチ系 | 相続税 | 家系樹の王冠を持つ死霊。「3,000万+600万×取り巻きの数」のバリアを正しく計算すると剥がせる |
| インボイス・ゴーレム系 | インボイス | 登録番号の刻印がある石巨人。刻印の真偽(T+13桁)を見抜くと関節が外れる |
| レジャー・ゴースト系 | 簿記 | 借方半身・貸方半身の幽霊。両半身に同額ダメージを与えないと再生する(貸借一致の体感) |
| エヴェイド・シャドウ系 | 脱税 | 仮装隠蔽の影。姿を消すが「証憑ライト」で照らすと実体化。倒すと重加算税の枷がドロップ |
| デュアル・クラーケン系 | 国際税務 | 二つの海(国)に足を伸ばす頭足類。租税条約の銛でしか二重の触手を断てない |

## 6.4 レアリティとドロップ(ディアブロ型)

- ドロップ等級: コモン/アンコモン/レア/エピック/**判例級(レジェンダリー)**
- 判例級素材は著名判例をモチーフにした固有装備の材料(効果もフレーバーも固有)
- **「知識で確率が上がる」**: 弱点看破のコンボ数がそのままドロップ率ブーストになる(最大+100%)。運ではなく理解がレアを引き寄せる

## 6.5 出題難度の階段

同一モンスターでもランクが上がると問いが深くなる。

- G〜E: 用語・数字の再認(4択)「青色申告特別控除の最高額は?」
- D〜C: 条件判断「電子申告なしの複式簿記、控除はいくら?」→55万
- B〜A: 事例計算「売上900万・経費300万・青色65万・基礎控除…課税所得は?」
- S〜SS: 税理士試験レベルの複合事例・判例趣旨(推理パートと連動)

# 7. 戦闘システム

## 7.1 基本フロー「看破バトル」

1. **エンカウント**: シンボルエンカウント。フィールドからシームレスに戦闘へ
2. **敵の「問い」**: 敵が攻撃の予備動作として問いを放つ(画面上部にカード表示、制限時間3〜10秒)
3. **応答**: 4択タップ/○×スワイプ/数値ダイヤル/並べ替えドラッグの4形式
4. **正解 → 看破**: 敵が硬直し弱点コアが露出。**攻撃フェーズ**(タップ連打+タイミングスワイプのアクション)でダメージ
5. **不正解 → 被弾**: 敵の攻撃が直撃。状態異常のリスク
6. 敵HPを削り切ると討伐。**トドメの一問**(そのモンスターの核心論点)で報酬倍率が決まる

## 7.2 コンボと爽快感

- 連続正解で**看破コンボ**: ×1.2 → ×1.5 → ×2.0 → **「完全論破」**(画面全体カットイン)
- 正解の速さで会心率上昇(3秒以内=即答会心)
- **ここに開発予算の最重心を置く**: ヒットストップ、パーティクル、SE、コントローラ振動級のハプティクス。正解が「気持ちいい」ことが本作の生命線

## 7.3 状態異常(税ならではのリスク翻訳)

| 状態異常 | 効果 | 由来 |
|---|---|---|
| 追徴 | 所持金が毎ターン減少 | 追徴課税 |
| 延滞 | 継続スリップダメージ(時間経過で利率上昇) | 延滞税 |
| 加算の枷 | 与ダメージ35%減 | 重加算税35% |
| 無申告の霧 | ミニマップ・敵情報が見えない | 無申告加算税 |
| 源泉縛り | 獲得報酬から自動天引き | 源泉徴収 |

**回復手段も知識**: 「期限内申告の護符」「更正の請求の巻物」などの装備・スキルで解除。

## 7.4 属性相性(4属性)

申告(自ら計算)⇔ 賦課(お上が計算)、源泉(先取り)⇔ 流通(取引に乗る)の2軸4属性。
装備知識の属性と敵属性で相性ボーナス。**税の徴収方式の違い**が自然に頭に入る。

## 7.5 パーティとAI妖精レシー

- ソロ狩猟が基本。相棒レシーが誤答時に1日3回まで「ヒントの光」を出せる(ヒント使用は図鑑に記録され、後日その論点の敵が優先リポップ=弱点復習)
- マルチ協力狩猟(最大4人): 大型ボスで役割分担(問いの分野が各人に割り振られる→**教え合いが自然発生**)

## 7.6 ボス戦(大型狩猟)

- 多段フェーズ+部位破壊。部位=論点(例: 法人税ドラゴンの「損金の左翼」「益金の右翼」「申告期限の尻尾」)
- 最終フェーズは**総合事例**: それまで部位破壊で集めた情報を使う計算問題。電卓UIが「魔導計算盤」として登場
- 敗北しても部位破壊の進捗と図鑑ヒントは持ち越し(**負けるほど勝ちに近づく**設計)

## 7.7 難易度保証

- 出題はプレイヤーごとの習熟度モデル(第25節)で動的調整。正答率が常に**60〜85%帯**に収まるよう出し分け(フロー状態の維持)
- 3連続誤答で自動的に1段易しい問いへ(プレイヤーには「敵が弱った」と見せる)

# 8. 推理システム「税務調査ファイル」

## 8.1 コンセプト

法廷推理ゲームの骨格(証拠収集→尋問→矛盾の突きつけ)を**税務調査**に置き換えた、章仕立てのアドベンチャーパート。戦闘が「点の知識」なら、推理は**「知識のつながり」**を学ぶ場。

## 8.2 フロー

1. **依頼**: ギルドに事件が持ち込まれる(例: 「美食通りの店主が、身に覚えのない申告漏れを疑われている」)
2. **現場調査**: フィールドを歩き**徴憑**を収集(領収書・請求書・帳簿・契約書・通帳・レジデータ・タイムカード…)。タップで拡大し、日付・金額・名義・但し書きを自分で読む
3. **帳簿整理**: 集めた徴憑を「帳簿ボード」にドラッグして仕訳(=簿記の実技が推理の道具になる)
4. **証言・尋問**: 関係者の証言に「ゆさぶり」「つきつけ」。証言と徴憑の**矛盾**を発見
5. **論破**: 矛盾の核心を突く選択+根拠となる知識(装備している知識カード)を提示
6. **解決**: 真相開示。冤罪を晴らす/本当の不正を暴く。信頼度・報酬・図鑑「判例の頁」獲得

## 8.3 矛盾の例(第4章「消えた市場の対価」)

- 証言「全部テイクアウト販売です(8%)」⇔ 徴憑: 店内のテーブル席の写真+「店内飲食」と印字されたレシート → 軽減税率の適用誤り
- 証言「この機械は今年買った」⇔ 通帳: 3年前の振込記録 → 減価償却の起算年の偽り

## 8.4 レベルデザイン

- 各章1事件+月1配信のスピンオフ事件(運営型)
- 上位事件は**プレイヤー自身が申告書を作成して提出する**(帳簿→決算書→申告書の一気通貫演習を「事件解決の書類」として偽装)

## 9.2 信頼度システム(コミュ)

# 10. 装備システム「知識装備」

## 10.1 コンセプト

武器・防具は存在しない。**理解した知識そのものが装備**になる。装備スロットに知識カードをセットする=その知識で戦う宣言。

## 10.2 装備スロット

- **主知識**(武器相当)×1、**守り知識**(防具相当)×2、**心得**(アクセサリ相当)×3
- スロット数はハンターランクで拡張

## 10.3 装備例

| 知識装備 | 種別 | 効果 | 入手 |
|---|---|---|---|
| 青色申告書・六十五万光 | 主知識 | 会心率+20%/申告属性強化 | 青色スライム素材×推理1章 |
| 小規模企業共済の盾 | 守り | 防御+30%/「追徴」耐性 | ガロン社長信頼Lv7 |
| iDeCoの泉 | 心得 | MP毎ターン回復(ただし60ターン引出不可のロック付き=制度の翻訳) | 雪山隠しエリア |
| NISAの双剣 | 主知識 | 会心発生時、追撃が非課税(=消費されない) | 黄金遊園地 |
| 損益通算の環 | 心得 | 被ダメージの一部を次の与ダメに合算 | 草原地下水脈 |
| 電子帳簿の護符 | 守り | 徴憑を紛失しない/検索性+(推理パートで検索UI解禁) | 機械首都 |
| ふるさと納珠 | 心得 | 使った所持金の一部が翌日返礼素材になる | デイリー累積 |

**効果はすべて制度の性質の比喩**になっており、装備説明文がそのまま制度解説として図鑑に転記される。

## 10.4 強化と「理解度」

- 装備には**理解度ゲージ**があり、その論点の問いに正解するたび成長(最大+50%効果)
- 長期間その論点に触れないと理解度が緩やかに減衰(忘却の可視化)→ リポップ討伐で即回復

# 25. データベース設計

## 25.1 全体構成(Firebase)

- **Cloud Firestore**: プレイヤーデータ・進行・ソーシャル
- **Cloud Storage + CDN**: アセットバンドル、問題パック(署名付き)
- **Cloud Functions**: 検証ロジック、ランキング集計、AI中継、改正パイプライン
- **Remote Config**: イベント切替、動的難度パラメータ、A/Bテスト
- **BigQuery(連携)**: 学習ログ分析(習熟度モデル訓練)

## 25.2 主要コレクション

```
/players/{uid}
  profile: {name, rank, level, job, createdAt}
  mastery/{topicId}: {theta, correct, wrong, streak, lastSeenAt, nextReviewAt}  # 習熟度+SRS
  inventory/{itemId}, equipment/{slot}, codex/{entryId}, npcs/{npcId}: {trust, flags}
  quests/{questId}: {state, progress}

/content (バージョン管理・読み取り専用)
  /monsters/{id}          # 第6.3節スキーマ
  /questions/{id}         # 下記25.3
  /topics/{id}            # 知識体系ツリー(税目→単元→論点)
  /items, /skills, /npcs, /quests, /cases(推理), /fields

/law_versions/{fiscalYear}   # 第28節: 年度別の法令パラメータ
/seasons/{seasonId}, /rankings/{boardId}
```

## 25.3 問題データスキーマ(中核)

```json
{
  "id": "Q-AOI-012",
  "topicId": "T-INC-BLUE-65",
  "type": "choice4 | ox | dial | order | case",
  "difficulty": 3.2,
  "lawRefs": [{"law": "措法25の2", "paramKey": "blue_deduction_max"}],
  "stem": "電子帳簿保存またはe-Taxで申告する複式簿記の者。特別控除の最高額は?",
  "params": {"blue_deduction_max": "@law:2026:blue_deduction_max"},
  "choices": ["{{blue_deduction_max}}円", "55万円", "10万円", "38万円"],
  "answer": 0,
  "explanation_short": "…(レシーの30秒解説)",
  "validFrom": "2020-01-01", "validTo": null,
  "reviewStatus": "approved", "reviewer": "tax-cpa-004"
}
```

**要点**: 金額・率・期限などの**改正されうる数値は問題文に直書きせず`@law:年度:キー`参照**にする。年度パラメータ表の差し替えだけで問題群が一括更新される(第28節)。

## 25.4 習熟度モデル

- 項目反応理論(IRT 2PL)ベース: プレイヤーθ×問題難度で正答確率を推定し、60〜85%帯に入る問いを出題
- SRS: SM-2改(間隔1→3→7→16→35→90日)。`nextReviewAt`が「リポップ時刻」
- 全応答をイベントログ化→BigQueryで難度キャリブレーションを月次再推定

## 25.5 不正対策

- 回答判定はサーバ検証(Cloud Functions)。報酬付与もサーバ側
- 問題パックは暗号化配信・端末内復号。答えのクライアント埋め込み禁止

# 27. AI連携設計

## 27.1 AI税理士「庵(いおり)のレシー」

章2クリアで解放される相談所。プレイヤーが自然文で入力:

> 「今年フリーランスの利益500万。来年住宅購入予定で、子どもも生まれる」

**AIの応答(2段構成)**:
1. **一般情報としての整理**(実法令ベース): 青色申告特別控除、小規模企業共済、住宅ローン控除の要件、出産育児一時金・扶養の変化…を平易に説明(「個別の税務助言ではない」を常時明示)
2. **クエスト変換**: 関連論点をゲーム内クエスト連鎖として自動生成
   - 「草原の〈青色スライム上位種〉を討伐せよ」
   - 「雪山の〈共済ゴーレム〉から守りの知識を得よ」
   - 「癒しの岬で〈住宅借入金の間取り図〉を集める推理事件」

## 27.2 技術構成

- OpenAI API(Function Calling)+ **RAG**: 検索対象は自社監修済み知識ベース(law_versions+制度図鑑テキスト)のみ。**モデルの素の知識で税額を断定させない**
- クエスト変換は`create_quest_chain(topicIds[])`のツール呼び出し→サーバ側で既存クエストテンプレにマッピング(AIが未知のゲーム内容を捏造しない)
- ガードレール: 個別具体的な税額の断定・脱税相談は定型応答で税理士相談へ誘導。入力PIIはマスキングし学習利用しない
- コスト設計: 応答はトピック単位でキャッシュ。1ユーザー日次上限あり(超過時はレシーが「明日また来てね」)

## 27.3 AIの裏方利用

- 問題ドラフト生成(→必ず税理士レビューを通してから`approved`)
- NPC雑談の動的バリエーション(固定スクリプトの言い回し展開のみ。設定・事実は固定データ)
- 誤答パターン分析からの「つまずき解説」パーソナライズ

# 28. 最新税制へ自動更新できる仕組み

## 28.1 法令パラメータレイヤ(第25.3節と連動)

```
/law_versions/2026/
  blue_deduction_max: 650000
  basic_deduction: {table: 所得階層別}
  consumption_rate: {standard: 0.10, reduced: 0.08}
  inheritance_basic: {base: 30000000, per_heir: 6000000}
  invoice_transition: {rate: 0.5, until: "2029-09-30"}
  ...
```

- 全問題・全装備効果・全図鑑記述は**キー参照**。年度切替=新バージョンの追加(旧年度も保持し、過去問イベントに利用)

## 28.2 更新パイプライン

1. **検知**: e-Gov法令API・官報・国税庁新着のクローラ(Cloud Scheduler)が差分を検出→税務コンテンツチームへ自動起票
2. **起票→改修**: 影響範囲ツール(lawRefs逆引き)が「この改正で影響を受ける問題123件・装備4件・図鑑9頁」を自動リストアップ
3. **監修**: 税理士2名のダブルチェックで`approved`
4. **配信**: 問題パック差分配信(アプリ審査不要)。ゲーム内では「改正の詔」イベントとして物語化
5. **猶予演出**: 施行前は新旧併記期間(「予言の頁」として新制度を先行図鑑化)

## 28.3 多国対応(将来)

`law_versions`を`/jurisdictions/{JP|US|...}/{year}`に拡張。知識体系ツリー(topics)は国別に差し替え、ゲームシステム・大陸資産は共通利用。
