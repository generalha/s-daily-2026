# 看破バトル Webプロトタイプ(検証版)

企画書の生命線である「看破バトル」(第7節)の面白さを最小コストで検証するためのプロトタイプ。

## 遊び方

`index.html` をスマホのブラウザで開くだけ。サーバー・ビルド・外部通信は一切不要(完全オフライン動作)。

- **フィールド探索**: 夜の「緑晶の草原」を画面ドラッグ(仮想スティック)で移動。金色に光る徴憑(領収書など)を拾い、徘徊するスライムに近づくと戦闘へ
- 敵の「問い」に制限時間内に回答 → 正解で看破 → 連打で攻撃(選択肢表示後0.6秒は誤タップ防止の構え時間)
- 討伐した魔物はフィールドから消える。狩り尽くすとしばらくしてリポップ
- 3.5秒以内の即答で会心率アップ、連続看破でダメージ倍率上昇(最大×2.0)
- 5連続看破で「完全論破」カットイン
- 敵のHPを削り切ると「トドメの一問」→ 正解で討伐、報酬ドロップ率+知識ブースト
- 誤答・時間切れは被弾。ただし図鑑にヒントが刻まれる(敗北=図鑑が育つ)
- 図鑑(大税典)は端末のlocalStorageに保存

## 収録内容

- フィールド: 緑晶の草原(1800×1400、カメラ追従、Canvas描画、装飾は固定シード配置)
- 敵: 青色スライム・アオイロン(ランクG)×3体(フィールド徘徊)+ 徴憑採取ポイント×4
- 問題: 所得税・消費税・青色申告など入門20問+トドメの一問(監修前・検証用)
- 出題は易→難の固定順(テスト時の条件を揃えるため)

## 10人テストで見るべきこと

1. **「もう1回」と言うか**(リザルト画面から再戦した回数を聞く)
2. **「勉強っぽい」と言われないか**(言われたらどの瞬間かを特定する)
3. 正解時の爽快感が伝わるか(音・振動・連打)
4. 問題の難度が適切か(全滅する人/簡単すぎる人の割合)

## 技術メモ

- 依存ライブラリゼロの単一HTML。効果音はWebAudioで動的生成、振動はVibration API
- 本番では問題データを `@law:年度:キー` 参照+Firebase配信に置換する(企画書 25.3 / 28節)
- 免責: 収録している税知識は一般的情報であり、個別の税務助言ではない
