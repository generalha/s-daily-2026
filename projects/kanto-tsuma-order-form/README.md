# 關東太太 注文・発送・利益管理フォーム

台湾向け代購（代理購入）販売「關東太太」用の、注文入力〜発送管理〜利益集計を
Googleフォーム＋スプレッドシートだけで完結させるためのセットアップ一式です。

## これで作られるもの

Apps Scriptを1回実行するだけで、以下がすべて自動生成されます。

- **Googleフォーム**「關東太太 注文・発送管理フォーム」（**注文者＝お客様**が直接入力する画面）
- **回答スプレッドシート**（同名＋「回答」が付いたファイル）の中に3つのシート
  - `回答` … フォームの回答が自動で溜まる。右側に妻が入力する管理欄（販売価格・
    仕入れ値・支払い状況・発送状況など）と、注文ID・円換算売上・粗利益・利益率・
    EMS用コピペ・案内文の下書きが**数式で自動計算**される列がある
  - `設定` … 為替レートなど、変更したい数値をまとめた場所
  - `ダッシュボード` … 総売上・総粗利益・未入金件数・未発送件数・
    商品別売上ランキング・商品別粗利益ランキングを自動集計

## 運用方針（このシステムが大事にしていること）

1. **フォームは注文者（お客様）が入力する**：注文者名・販売先・商品カテゴリー・
   ご希望の商品・数量・お届け先住所・お届け先電話番号・メモのみを入力してもらいます。
2. **販売価格はお客様に入力させない**：金額の入力ミス・言い間違いを防ぐため、
   販売価格（台湾ドル）はフォームに含めません。注文確認後、妻がLINE等での
   やり取りをもとに確定額を回答シートへ入力します。
3. **原価情報もお客様に見せない**：仕入れ価格・支払い状況・発送状況などは
   フォームには含めず、注文が入った後に妻が回答シートへ直接入力します。
4. **発送に必要な最低限の情報だけは例外的に収集する**：EMS発送にはお届け先
   住所・電話番号が必須のため、今回はこの2項目のみフォームに含めています。
   ※これは個人情報です。回答スプレッドシートの共有範囲は**必ず妻（自分）だけ**に
   絞ってください（詳しくは「個人情報の取り扱いについて」を参照）。
5. **妻の入力負担も最小に**：妻が触るのは回答シートの黄色い列（J〜Q列）だけ。
   販売価格・支払い状況・発送状況・発送方法は入力や選択だけで済み、ID採番・
   円換算・利益計算・コピペ用テキスト・案内文はすべて自動計算されます。
6. **EMSへの完全自動入力はしない**：まずは「EMS用コピペ欄」の1行テキストを
   コピーして、EMSの発送手続き画面やラベルに手作業で貼り付ける運用にします。
   自動化は必要になった時点で改めて検討します。

## 注文の流れ（全体像）

1. **お客様がフォームに入力**：商品選択・数量・お届け先情報を入力
2. **回答シートに自動で1行追加**：注文ID・EMS用コピペ・案内文が自動生成される
   （販売価格が未入力のため、この時点では売上・粗利益は0円扱い）
3. **妻が回答シートの黄色い列に入力**：販売価格・仕入れ値・送料・支払い状況・
   発送状況・発送方法・重量・追跡番号を確認しながら入力 → 粗利益・利益率が自動確定
4. **案内文をコピペしてお客様に連絡**：商品・数量・金額・発送方法・お届け先を案内
5. **EMS発送時にコピペ欄を使用**：注文者・商品名・数量・発送方法・重量・価格・
   住所・電話・メモがまとまった文字列をEMSの発送手続き画面に手動転記
6. **ダッシュボードで随時確認**：総売上・総粗利益・未入金件数・未発送件数・
   商品別ランキングを自動集計で把握

## セットアップ手順（初回のみ・約5分）

### 1. Apps Scriptプロジェクトを新規作成する

1. ブラウザで https://script.google.com/ を開く（Googleアカウントでログイン）
2. 「新しいプロジェクト」をクリック
3. 左上のプロジェクト名（「無題のプロジェクト」）を「關東太太 注文管理セットアップ」
   などわかりやすい名前に変更する

### 2. コードを貼り付ける

1. 中央のエディタに元から入っている `function myFunction() {}` を全部削除する
2. このフォルダの `Code.gs` の中身を**全部コピー**して貼り付ける
3. 上部の保存アイコン（💾）またはCtrl+S（Macはcommand+S）で保存する

### 3. 実行する

1. エディタ上部の関数選択プルダウンで `setupKantoTsumaSystem` を選ぶ
2. 「実行」ボタン（▶）を押す
3. 初回は「承認が必要です」と表示されるので、
   `権限を確認` → 自分のGoogleアカウントを選択 →
   「このアプリは Google で確認されていません」と出たら
   `詳細` → `（プロジェクト名）に移動（安全ではないページ）` → `許可`
   の順に進む
   （※ 自分で書いた／貼り付けたスクリプトなので問題ありません）
4. 実行が終わると、下部の「実行ログ」に以下のようなURLが出力されます。
   - フォーム編集URL
   - フォーム回答URL（**注文者に共有する画面**）
   - スプレッドシートURL

### 4. 個人情報の取り扱いについて（重要）

このフォームはお届け先住所・電話番号を収集するため、回答スプレッドシートには
お客様の個人情報が入ります。セットアップ後、必ず以下を確認してください。

1. スプレッドシートの右上「共有」ボタンを開く
2. 「リンクを知っている全員」などになっていないか確認し、**自分（妻）のアカウント
   だけ**がアクセスできる状態にする
3. フォーム自体は回答者に共有してOK（フォームの回答は編集者以外には見えません）

### 5. URLを使い分ける

- **フォーム回答URL** … LINEオープンチャットの固定メッセージやFacebook投稿など、
  注文者が自分で開ける場所に貼っておく（例：「ご注文はこちらのフォームから」）。
- **スプレッドシートURL** … 妻だけが開く、社内管理用のページ。注文者には共有しない。

これでセットアップは完了です。**もう一度スクリプトを実行しても、
2回目以降はフォームが重複して作られることはありません**
（既存のURLがログに表示されるだけです）。

## 日常の使い方

### 注文が入ったら（お客様がフォームに入力）

1. お客様がフォーム回答URLを開いて、注文者名・販売先・商品カテゴリー・
   ご希望の商品・数量・お届け先住所・お届け先電話番号・メモを入力する
2. `回答` シートに自動で1行追加され、注文ID・EMS用コピペ・案内文の下書きまで
   自動で入る（この時点では販売価格が未入力のため売上・粗利益は0円扱い）

### 注文確認後（妻が回答シートを更新）

1. `回答` シートを開き、該当行の**黄色い列（J〜Q列）**に以下を入力する
   - 販売価格（台湾ドル）… LINE等でご案内・合意した金額を入力
   - 仕入れ価格（日本円）
   - 国内送料（日本円）
   - 支払い状況（プルダウンから選択）
   - 発送状況（プルダウンから選択）
   - 発送方法（プルダウンから選択）
   - 重量（グラム）
   - 追跡番号
2. 入力すると、売上・粗利益・利益率・EMS用コピペ・案内文が自動で更新される

### お客さんに発送方法・金額を案内したいとき

1. `回答` シートの該当行、`案内文の下書き` 列（X列）のセルを開く
2. 中身を丸ごとコピーして、LINEやFacebookメッセージに貼り付ける
3. 必要に応じて文面を軽く調整する（送料はこの時点では未確定の想定です）

### EMSで発送するとき

1. `回答` シートの該当行、`EMS用コピペ` 列（W列）を開く
2. 「注文者名｜商品名｜数量｜発送方法｜重量｜販売価格｜住所｜電話｜メモ」が
   1行にまとまっているので、コピーしてEMSの窓口・システムに貼り付けて使う
   （現時点では手作業での転記です。自動連携は行っていません）

### 為替レートを更新したいとき

1. `設定` シートを開く
2. B2セルの数値（初期値 `0.25`）を書き換える
3. `回答` シートの円換算売上・粗利益・利益率、`ダッシュボード` の集計は
   **自動で再計算**されます（他の操作は不要）

**B2の意味**：「1円は台湾ドルにするといくらか」を表す数値です。
売上（円）＝ 販売価格（台湾ドル）÷ B2 で計算しています。

例：1台湾ドル ＝ 約4.6円のとき、B2 ＝ 1 ÷ 4.6 ≒ `0.217`

台湾の銀行やGoogleで「TWD JPY レート」を検索し、月1回程度の頻度で
見直すことをおすすめします。実勢レートよりわずかに厳しめ（円換算が
少なめに出る）数値にしておくと、利益を大きく見積もりすぎずに済みます。

### 売上・利益・未処理件数を確認したいとき

`ダッシュボード` シートを開くと、以下が自動集計されています。

- 総売上（円換算）
- 総粗利益（円）
- 未入金件数（支払い状況が「入金済み」以外の件数。未入力の新規注文も含む）
- 未発送件数（発送状況が「発送済み」以外の件数。未入力の新規注文も含む）
- 商品別 売上ランキング
- 商品別 粗利益ランキング

すべて数式なので、`回答` シートにデータが増えるたびに自動更新されます。
**ダッシュボードのセルには手入力しないでください**（数式が消えてしまいます）。

## フォームの入力項目一覧（注文者＝お客様が入力）

| 項目 | 種類 | 必須 |
|---|---|---|
| 注文者名 | 短文 | ○ |
| 販売先（どちらでご注文いただきましたか） | プルダウン（LINEオープンチャット／個別LINE／Facebook／その他） | ○ |
| 商品カテゴリー | プルダウン（戰鬥陀螺／童鞋／周邊商品／食品／その他） | ○ |

| お届け先住所（台湾） | 段落 | ○ |
| お届け先電話番号 | 短文 | ○ |
| メモ（ご要望などあれば） | 段落 | 任意 |

販売価格・仕入れ価格・支払い状況・発送状況などの社内管理情報は、お客様には
見せず・入力させず、注文確認後に妻が回答シートへ直接入力します（下記）。

## 回答シートの列構成

| 列 | 内容 | 入力元 |
|---|---|---|
| A | タイムスタンプ | フォーム自動 |
| B〜I | フォームの回答（注文者名〜メモ） | フォーム自動 |
| J | 販売価格（台湾ドル） | **妻が入力** |
| K | 仕入れ価格（日本円） | **妻が入力** |
| L | 国内送料（日本円） | **妻が入力** |
| M | 支払い状況 | **妻がプルダウンで選択** |
| N | 発送状況 | **妻がプルダウンで選択** |
| O | 発送方法 | **妻がプルダウンで選択** |
| P | 重量（グラム） | **妻が入力** |
| Q | 追跡番号 | **妻が入力** |
| R | 注文ID（`KT-0001`形式の連番） | 数式で自動計算 |
| S | 為替レート（使用値） | `設定`シートを参照 |
| T | 売上（円換算） | 数式で自動計算 |
| U | 粗利益（円） | 数式で自動計算 |
| V | 利益率 | 数式で自動計算 |
| W | EMS用コピペ | 数式で自動計算 |
| X | 案内文の下書き | 数式で自動計算 |

J〜Q列（薄い黄色の背景）が妻の作業範囲です。M・N・O列はプルダウンになっており、
セルをクリックして選ぶだけで入力できます（自由入力によるタイプミスを防止）。

R〜X列は `ARRAYFORMULA` という数式で自動的に下の行まで計算されるように
なっているので、フォームに新しい回答が入るたびに自動で反映されます。
誤って数式を消してしまわないよう、この範囲には編集時に警告が出るように
設定してあります（入力を止めるものではないので、通常の運用に支障はありません）。

## よくある質問

**Q. 2回スクリプトを実行してしまったら？**
A. 問題ありません。2回目以降は新しいフォームは作られず、既存のURLが
ログに表示されるだけです（実行ログは Apps Script エディタ下部の
「実行数」→該当の実行をクリックすると確認できます）。

**Q. 質問項目を追加・変更したい**
A. Googleフォームの編集画面から直接、質問の追加・順番の変更・選択肢の
追加ができます（フォームの通常の編集操作でOKです）。ただし、`回答`シートの
列がずれると自動計算式の列参照（J列＝販売価格など）がずれてしまうため、
質問の並び順を変えた場合は `回答`シートのJ〜X列の数式・データ入力規則を
列の位置に合わせて調整してください。

**Q. なぜ販売価格や仕入れ価格をフォームに入れないのですか？**
A. 販売価格はお客様の入力ミス・認識違いを避けるため、仕入れ価格は原価が
見えてしまうことを避けるためです。これらは注文確認後に妻が回答シートへ
直接入力する運用にしています。

**Q. 住所・電話番号を収集して大丈夫？**
A. EMS発送に必須の情報なので今回は収集する設計にしていますが、個人情報です。
回答スプレッドシートは必ず妻（自分）のみがアクセスできる設定にしてください
（「個人情報の取り扱いについて」を参照）。むやみにコピー・共有しないよう
注意してください。

**Q. もう一度最初から作り直したい**
A. 作成されたフォームとスプレッドシートをGoogleドライブでゴミ箱に入れたあと、
Apps Scriptエディタで以下を一度だけ実行すると、セットアップ状態がリセットされ、
再度 `setupKantoTsumaSystem` を実行できるようになります。

```javascript
function resetKantoTsumaSetup() {
  PropertiesService.getScriptProperties().deleteProperty('KANTO_TSUMA_FORM_ID');
  PropertiesService.getScriptProperties().deleteProperty('KANTO_TSUMA_SHEET_ID');
}
```

このリセット関数は `Code.gs` の一番下に貼り付けてから実行してください。
