# 保育料算定における同居祖父母等の所得割合算 — 自治体運用比較表

保育所入所時の保育料(利用者負担額)算定において、児童と同居する祖父母等(父母以外の親族)の
市町村民税所得割を合算するか否かの運用を、関東を中心に**47自治体**調査した結果の一覧
(うち**34自治体**で運用内容をソース付きで確認)。

- 調査時期: 2026年8月
- 調査方法: 各自治体公式ページ・公式PDF(入所案内等)・例規集を対象としたウェブ調査
- 信頼度の定義:
  - **中**: 自治体公式ページ/公式PDF/例規集を出典とする検索結果で内容を確認(原文全文の直接閲覧は当調査環境の制約により不可)
  - **低/未確認**: 公式ソース上で運用の記述を特定できず
- 注意: 数値基準は改定されることがあるため、実務利用の前に必ず原典・担当課で最新情報を確認すること

### 全自治体に共通する構造

1. **原則は父母の所得割合算**で階層決定(全34自治体共通)
2. 父母が**低所得(非課税〜年収100〜180万円・生活保護基準)** の場合に限り、同居祖父母等の税額を使用または合算
3. 合算対象は**同居祖父母等のうち最多所得(最多税額)の1名**(「家計の主宰者」「生計の中心者」)とする運用が支配的
4. **「同居」の判定は住民票の世帯ではなく住所(地番・同一建物)** による自治体が明文化例で多数(上尾・小山・流山)——世帯分離だけでは別生計にならない
5. 別生計を認める入口は「同居関係にないこと(=生計が別であること)を証明する書類の提出」(上尾市FAQ が明文化)
6. 未申告・書類不提出の場合は**最高階層で決定**(取手・日立・上尾ほか)

この共通構造が、`判断フローチャート.md` の決定的判定フローの根拠である。
