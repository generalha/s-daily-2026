# 保育料算定に係る生計状況申立書(同居祖父母等との別生計申立て)

保育所入所時の保育料(利用者負担額)算定において、同居する祖父母等の市町村民税所得割を
**合算しない(別生計)** と判断してもらうために申請者(保護者)が提出する書式。

- `保育料算定に係る生計状況申立書.docx` — 記入式のWord様式(A4・2ページ)
- `保育料算定に係る生計状況申立書.pdf` — 印刷用PDF(同内容)
- `保育料算定に係る生計状況申立書.md` — 内容のテキスト版(改版用)

## 設計の根拠(茨城県内自治体の運用調査)

2026年8月時点でウェブ上で確認できた県内自治体の運用:

| 自治体 | 運用 |
|---|---|
| つくば市 | 父母の市民税所得割で算定が原則。ただし①他親族が児童・保護者を税や健康保険の扶養に入れている場合、②他親族が実質的な「家計の主宰者」である場合は、その親族分を合算。別居時は「別居監護申立書」など申立書方式を採用 |
| 土浦市 | 父母の年収が103万円未満の場合、同居祖父母の税額を合算 |
| 阿見町 | 父母の年収100万円以下の場合、祖父母(税額の高い方)で決定。同居の実態(部屋の共有等)により一世帯の家計とみなす |
| 水戸市ほか | 保護者の課税状況で階層決定(詳細基準は担当課判断)。県内外の一般運用として「同居親族のうち最多所得者を家計の主宰者とみなして合算」が広く用いられる |

共通する判断要素(国の旧徴収基準および日本年金機構「生計同一関係に関する申立書」とも整合):

1. **住民票**: 世帯分離の有無(ただし世帯分離のみでは別生計と認めない)
2. **住居の独立性**: 二世帯住宅か、玄関・台所・浴室・光熱水道メーターの別
3. **家計の独立性**: 家賃・光熱水費・食費等を誰が負担しているか、生活費の授受の有無
4. **扶養関係**: 税法上・健康保険上の扶養に入っていないこと
5. **父母の収入**: 独立して生計を維持できる収入があるか(目安: 年収100〜103万円)

本様式はこれらすべてを1枚の申立書でカバーし、疎明資料のチェックリストと
誓約・同意欄(虚偽判明時の遡及再算定への同意)を備えた「もっとも無難な」構成とした。

## 利用時の注意

- 宛名(市町村長名)・提出先・様式番号は各自治体に合わせて調整すること
- 添付書類の要否・種類は自治体により異なるため、提出前に担当課へ確認すること
- 父母の収入が自治体基準(概ね100〜103万円)を下回る場合、この申立てによらず
  合算と判断される運用の自治体もある(土浦市・阿見町など)

## 改版方法

生成スクリプト(docx-js)から再生成する。テキスト版(`.md`)を修正したうえで
スクリプトに反映し、`node make_form.js` で `.docx` を再出力する。
