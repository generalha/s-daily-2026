# 2026-08-02 — 卸売(転売屋向け)マーケティング戦略

副業候補の一つ「日本現地仕入れ代行」事業について、ターゲットを個人客(B2C)から転売屋(B2B/卸)へ切り替えるマーケティング方針の意思決定メモ。

## 背景・方針転換

これまでの「かわいい」「限定」といった個人客向けの情緒的な訴求ではなく、**転売屋が仕入れ判断をするために必要な業務情報を前面に出す**方向へ転換する。転売屋の意思決定基準は「利益率が読めるか」「在庫リスクを負わずに済むか」「継続的に商材を供給されるか」の3点に集約されるため、訴求もこの3点に合わせる。

## 1. 卸条件の明示(個人客向け表記からの脱却)

個人向けの装飾的な文言を廃し、以下を常設の一次情報として掲載する。

| 項目 | 内容 |
|---|---|
| 仕入単価表 | 商品カテゴリ別・数量帯別の単価を一覧化(PDF/スプレッドシートで即DL可能に) |
| MOQ(最低ロット) | 商品・カテゴリごとに明記。曖昧な「応相談」は避ける |
| まとめ買い割引 | 数量帯ごとの割引率テーブル(例: 10個〜/50個〜/100個〜) |
| 同梱発送対応 | EMS・航空便での複数商材の同梱発送可否と送料目安を明記 |

→ 転売屋が「電卓を叩ける」状態にすることが目的。価格が不透明だと候補から外れる。

## 2. 「日本現地仕入れ代行」であることの明示

- 事業モデルを「代行(委任)」として明確に打ち出す。転売屋自身が在庫を先に抱える必要がないことを一次訴求とする。
- 「在庫リスクを転売屋側が負わない」= 受注後仕入れ・実需ベースでの調達であることを明記し、資金拘束・売れ残りリスクへの不安を解消する。
- 「現地(日本)にいるからこそ入手できる」という調達力の裏付け(実店舗巡回・限定入荷情報へのアクセスなど)を信頼要素として添える。

## 3. 入荷速報の定期配信による集客導線

- LINE公式アカウント / Facebookページで「入荷速報」を定期配信し、転売屋が"次の商材"を探しに戻ってくる導線を作る。
- 配信は一方向の告知に留めず、以下を型として繰り返す:
  - 商品名・仕入単価・残数(MOQ到達までの目安)
  - 過去販売実績や回転の速さ(社会的証明)
  - 次回入荷予定・締切(緊急性)
- 友だち追加/ページいいねを起点にした継続接点を作り、都度の新規集客コストを下げる。

## 副業制限リスクとの接続(baseline.mdより)

baseline.md で挙げた弱みの一つに「副業制限: 認められる範囲(投資・不動産・執筆・家業手伝い・公益活動)に絞り込む」がある。**仕入れ代行業(継続的な卸売・取引仲介)は、上記の許容カテゴリに明確には該当しない可能性が高い**。マーケティング戦略の実行前に、以下を先に確認すること:

- [ ] 所属先の服務規程上、この事業モデルが副業許可の対象範囲に入るか
- [ ] 必要であれば事前に許可申請を行う
- [ ] 事業を進める場合の名義・実務運営(本人名義でよいか、家族名義にするか等)

マーケティング戦略そのものは合理的だが、**実行の前提として副業制限の確認を最優先の意思決定事項とする**。
