# LINE注文フォーム(Googleスプレッドシート + Apps Script)

LINEオープンチャット/LINEチャットで受けていた注文を、URLから開ける注文フォームで
受け付け、Googleスプレッドシートに自動保存するシステムです。

## 構成

```
line-order-form/
├── SETUP.md          # セットアップ手順・運用マニュアル(まずこちらを読む)
├── gas/
│   ├── Code.gs       # サーバー側プログラム(Google Apps Script)
│   ├── Form.html     # お客様用 注文フォーム(スマホ最適化)
│   ├── Status.html   # お客様用 注文状況確認ページ(進捗タイムライン)
│   └── Admin.html    # 管理者ページ(注文一覧・梱包・発送・集計)
└── cowork-skill/
    └── japanpost-intl-entry/ # Claude Cowork用 発送ラベル自動入力スキル(日本郵便)
```

## 主な機能

- お客様・管理者どちらも同じフォームから注文入力可能(入力者を自動記録)
- **顧客マスター**: 注文客に顧客Noを自動採番。管理者の代理入力時は顧客Noで
  氏名・お届け先を呼び出せる(管理者キー必須・お客様からは読み出し不可)
- LINEオープンチャット名 + LINEアカウント名の両方を入力可能
- 商品マスター登録済み商品は**台湾元価格を注文時に自動表示**、合計も自動計算
- マスターにない商品は自由入力で注文可能(価格は後から管理者が記入)
- 注文完了画面に**台湾郵便局の振込先口座**を表示
- 注文内容をワンタップコピーしてLINEに貼り付け可能
- **注文進捗の見える化**: お客様も管理者も注文単位の進捗バーで現在の状態がひと目で分かる
  (お客様は状況確認ページの進捗タイムライン、管理者は注文カードの進捗バー)
- **在庫管理**: 管理者が事前に在庫を登録。フォームに残数表示・売り切れ表示、在庫超えはブロック
- **承認フロー**: 注文は「承認待ち」で受付け、管理者の承認時に在庫を検証・確保して「注文確定」
  (同時注文による在庫超過は承認時に検出。確定後のキャンセルは在庫を自動で戻す)
- 注文番号を自動採番し、**番号で注文を呼び出して修正可能**(暗号キーを持つ管理者のみ)
- 梱包時に重量を入力すると**国際送料(EMS/国際小包)を自動計算**(料金表はシートで管理)
- 送料案内・発送完了のLINE用メッセージを自動生成、追跡番号・発送日を記録
- 日本郵便「国際郵便マイページ」の発送ラベル入力(台湾宛)を**Claude Coworkで自動化**するスキル付き
- 管理者ページ: ステータス管理(承認待ち→注文確定→入金確認済→梱包済→送料入金確認済→発送済)、
  梱包(計量・送料確定)、発送管理、商品集計(注文数と在庫の対比)、名前検索
- 新規注文のメール通知(任意)

導入方法は [SETUP.md](./SETUP.md) を参照してください。
