# LINE注文フォーム(Googleスプレッドシート + Apps Script)

LINEオープンチャット/LINEチャットで受けていた注文を、URLから開ける注文フォームで
受け付け、Googleスプレッドシートに自動保存するシステムです。

## 構成

```
line-order-form/
├── SETUP.md          # セットアップ手順・運用マニュアル(まずこちらを読む)
└── gas/
    ├── Code.gs       # サーバー側プログラム(Google Apps Script)
    ├── Form.html     # お客様用 注文フォーム(スマホ最適化)
    └── Admin.html    # 管理者ページ(注文一覧・梱包リスト・商品集計)
```

## 主な機能

- お客様・管理者どちらも同じフォームから注文入力可能(入力者を自動記録)
- LINEオープンチャット名 + LINEアカウント名の両方を入力可能
- 商品マスター登録済み商品は**台湾元価格を注文時に自動表示**、合計も自動計算
- マスターにない商品は自由入力で注文可能(価格は後から管理者が記入)
- 注文完了画面に**台湾郵便局の振込先口座**を表示
- 注文内容をワンタップコピーしてLINEに貼り付け可能
- 管理者ページ: ステータス管理(未対応→入金確認済→梱包済→受渡済)、
  梱包リスト(お客様別)、商品集計(仕入れ用)、名前検索
- 新規注文のメール通知(任意)

導入方法は [SETUP.md](./SETUP.md) を参照してください。
