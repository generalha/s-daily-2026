# LINE注文フォーム セットアップ手順

LINEオープンチャット/LINEでの注文受付を、URLひとつで使える注文フォームに置き換えるシステムです。
データはすべてGoogleスプレッドシートに保存されるので、いつでも見返せて消えません。

- **お客様**: URLを開く → 商品と数量を選ぶ → 送信 → 振込先(台湾郵便局)が表示される
- **管理者**: 管理者ページで注文一覧・梱包リスト・商品集計を確認、ステータス管理
- **費用**: 無料(Googleアカウントのみ必要)

---

## 1. スプレッドシートを作成する

1. [Google スプレッドシート](https://sheets.google.com) で新規スプレッドシートを作成
   (名前は自由。例:「注文管理2026」)
2. メニュー「**拡張機能 → Apps Script**」を開く

## 2. プログラムを貼り付ける

Apps Script エディタで以下の3ファイルを作成します。

| エディタ上のファイル名 | 貼り付ける内容 |
|---|---|
| `コード.gs` (最初からある) | `gas/Code.gs` の中身をすべて貼り付け(元の内容は削除) |
| `Form.html` (＋ → HTML で新規作成) | `gas/Form.html` の中身 |
| `Admin.html` (＋ → HTML で新規作成) | `gas/Admin.html` の中身 |

※ HTMLファイル名は大文字小文字も含めて **Form** / **Admin** と正確に付けてください。

保存(Ctrl+S / ⌘S)します。

## 3. 初期セットアップを実行する

1. スプレッドシートのタブに戻り、**ページを再読み込み**する
2. メニューに「**注文フォーム**」が増えているので、「**初期セットアップ(シート作成)**」をクリック
3. 初回は権限の承認画面が出ます:
   「権限を確認」→ 自分のアカウントを選択 → 「詳細」→「(プロジェクト名)に移動」→「許可」
4. もう一度「初期セットアップ」を実行すると、4つのシートが作成されます:
   - **商品マスター** — 販売する商品と台湾元価格
   - **注文一覧** — 注文が自動で記録される
   - **送料マスター** — EMS・国際小包の重量別料金表(国際送料の自動計算に使用)
   - **設定** — 振込先口座・管理者キーなど

   ※ すでに旧バージョンで運用中の場合も「初期セットアップ」を再実行すれば、
   注文一覧に発送用の列(重量・配送方法・国際送料・お届け先・追跡番号など)が自動追加されます。

## 4. 設定を入力する

### 「設定」シート

| 設定キー | 入力する内容 |
|---|---|
| 振込先_銀行名 | そのままでOK(台湾 中華郵政) |
| 振込先_郵局代号 | `700`(中華郵政の局番) |
| 振込先_口座番号 | **ご自身の郵便局口座番号**(例: `0000000-0000000`) |
| 振込先_口座名義 | 口座名義人のお名前 |
| 振込メモ | 注文完了画面に出す案内文(例:「振込後、チャットでお知らせください」) |
| 管理者キー | 自動生成済み。管理者ページURLに使う秘密の文字列(変更可) |
| 通知メール | 新規注文をメールで受け取りたい場合にアドレスを入力(不要なら空欄) |

### 「商品マスター」シート

| 列 | 内容 |
|---|---|
| 商品ID | 重複しないID(例: P001, P002…) |
| 商品名 | フォームに表示される商品名 |
| 価格(元) | **台湾元の価格**。注文フォームに自動表示されます |
| 表示順 | 小さい数字ほど上に表示 |
| 有効 | `有効` で表示 / `無効` で非表示(売り切れ時など) |

サンプル商品2件が入っているので、実際の商品に書き換えてください。

### 「送料マスター」シート(国際送料の自動計算)

| 列 | 内容 |
|---|---|
| 配送方法 | `EMS` / `国際小包(航空)` など。行を追加すれば配送方法を自由に増やせます(船便など) |
| 重量上限(g) | この重量**以下**ならこの料金、という上限値 |
| 料金(元) | 台湾元での送料 |

例: `EMS / 500 / 450` と `EMS / 1000 / 530` の2行があれば、
480g→450元、850g→530元 と自動計算されます。

> ⚠️ 初期データは**サンプル料金**です。発送は日本→台湾なので、
> **日本郵便の台湾宛料金表(EMS・国際小包)**を確認し、円を台湾元に
> 換算した金額(必要なら為替の変動分や手数料を上乗せ)に書き換えてください。
> お客様への請求は台湾元・台湾郵便局口座への振込です。
> 料金改定や為替変動があってもこのシートを直すだけで反映されます。

#### 日本郵便の台湾宛料金の調べ方

台湾はEMS・国際小包とも**第1地帯**(中国・韓国・台湾)です。公式料金表:

- EMS(第1地帯): https://www.post.japanpost.jp/int/charge/list/ems1.html
- 国際小包(第1地帯・航空/船便): https://www.post.japanpost.jp/int/charge/list/parcel1.html
- 料金・日数検索: https://www.post.japanpost.jp/cgi-charge/
- 台湾宛の条件・禁制品: https://www.post.japanpost.jp/cgi-kokusai/country.php?cid=44

参考(2025年時点の複数情報源で確認したEMS第1地帯の一部。**登録前に公式で要確認**):
500gまで1,600円 / 600g 1,750円 / 700g 1,900円 / 800g 2,050円 / 900g 2,200円(100gごと+150円)

円→元の換算例: レート1元=4.7円なら「円÷4.7」を切り上げ
(例: 1,600円 ÷ 4.7 ≒ 341元 → 350元で登録、など端数は上乗せ推奨)。
※SAL便は2024年以降取り扱い休止中のため、航空便か船便を使います。

## 5. ウェブアプリとして公開(デプロイ)する

1. Apps Script エディタ右上の「**デプロイ → 新しいデプロイ**」
2. 歯車アイコン → 種類「**ウェブアプリ**」を選択
3. 設定:
   - 説明: 任意(例:「注文フォーム v1」)
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**(お客様がGoogleログインなしで使うために必須)
4. 「デプロイ」→ 発行された **ウェブアプリURL** をコピー

### 発行されるURL

| 用途 | URL |
|---|---|
| お客様用フォーム | `(ウェブアプリURL)` |
| 管理者ページ | `(ウェブアプリURL)?page=admin&key=(管理者キー)` |
| 管理者による代理入力フォーム | `(ウェブアプリURL)?page=staff&key=(管理者キー)` |

管理者キーは「設定」シートの値です。**管理者用URLはお客様に共有しないでください。**

## 6. LINEでお客様に案内する

1. お客様用フォームのURLをコピー
2. URLが長いので、LINEオープンチャットの「**ノート**」や「**アナウンス(ピン留め)**」に貼るのがおすすめ
3. 必要なら短縮URLサービスで短くしてもOK

案内文の例:

> 📢 ご注文はこちらのフォームからお願いします!
> (URL)
> 商品と数量を選ぶだけでOK。送信すると振込先も表示されます。

## 日々の運用フロー

1. **お客様がフォームから注文** → 「注文一覧」シートに自動記録、完了画面に振込先を表示
   (お届け先住所も注文時に入力可能。後からLINEで聞いてもOK)
2. お客様が「注文内容をコピー」ボタンでLINEに貼り付け → チャット上でも確認できる
3. **商品代の入金を確認したら** → 管理者ページで該当注文を「入金確認済」に変更
4. **梱包・計量** → 「梱包」タブを開き、商品を梱包したら重量を量って入力。
   配送方法(EMS/国際小包)を選ぶと**国際送料が自動計算**され、
   「計量して梱包済にする」で送料が確定します
5. **送料の案内** → 「発送」タブの「送料入金待ち」で「📋 送料案内をコピー」→ LINEで送信
   (重量・送料・振込先入りのメッセージが自動生成されます)
6. **送料の入金を確認したら** → 「💰 送料入金確認済にする」
7. **発送** → 「発送待ち」でお届け先(台湾)を確認し、日本郵便の
   「国際郵便マイページサービス」で発送ラベルを作成。
   「📋 発送ラベル入力データをコピー」を使えばClaude Coworkでの自動入力も可能(後述)。
   追跡番号を入力して「✈️ 発送済にする」
8. **発送のお知らせ** → 「発送済」の「📋 発送完了メッセージをコピー」→ LINEで送信
   (追跡番号・追跡ページURL入り)

### 注文の呼び出し・修正(管理者のみ)

注文には自動で注文番号(例: `20260811-001`)が割り振られます。
修正は**暗号キー(設定シートの「管理者キー」)を知っている管理者だけ**が行えます。

1. 管理者ページ(`?page=admin&key=暗号キー`)を開く
2. 「注文一覧」タブ上部の入力欄に**注文番号を入力**して「✏️ 呼び出して修正」
   (または各注文カードの「この注文を修正」ボタンでもOK)
3. お客様情報・商品・数量・備考を変更して「保存する」

- 商品はプルダウンから選び直せます。マスター商品は**保存時に最新のマスター価格で再計算**されます
- 自由入力商品は単価を直接入力できます(空欄なら価格未定のまま)
- 修正すると備考欄に「【日時 修正】」の記録が自動で残ります
- 注文日時・ステータス・入力者(お客様/管理者)は修正しても維持されます
- 注文自体を取り消したいときは修正ではなくステータスを「キャンセル」にしてください

※ 呼び出し・修正はすべてサーバー側でも暗号キーを検証しているため、
URLやキーを知らないお客様が注文番号だけで他人の注文を見たり書き換えたりすることはできません。

### ステータスの意味

| ステータス | 意味 |
|---|---|
| 未対応 | 注文直後(商品代の入金待ち) |
| 入金確認済 | 商品代の振込を確認した → 「梱包」タブに表示される |
| 梱包済 | 計量・送料確定が完了した(送料の入金待ち)→ 「発送」タブに表示される |
| 送料入金確認済 | 送料の振込を確認した(発送待ち) |
| 発送済 | EMS/国際小包で発送した(追跡番号・発送日を記録) |
| 受渡済 | お客様の受け取りを確認した(任意で使用) |
| キャンセル | キャンセルされた注文 |

## 便利機能まとめ

- **台湾元の自動表示**: 商品マスターに登録済みの商品は、注文時に価格と合計が自動表示
- **自由入力商品**: マスターにない商品もお客様が名前入りで注文可能(価格は後で「注文一覧」シートの単価・小計欄に直接記入すればOK)
- **注文番号の自動採番**: `20260811-001` 形式で毎日リセット
- **注文番号で呼び出して修正**: 管理者ページで番号を入力すると注文を呼び出して編集可能(暗号キー必須・管理者のみ)
- **梱包リスト**: 入金確認済の注文だけをお客様単位で表示。梱包ミス防止に
- **国際送料の自動計算**: 梱包時に重量を入力するとEMS/国際小包の送料を送料マスターから自動計算。配送方法は選択式で、料金表はシートで自由に更新可能
- **送料案内・発送完了メッセージの自動生成**: 重量・送料・振込先・追跡番号入りのLINE用メッセージをワンタップでコピー
- **発送ラベル入力データのコピー**: 宛先・内容品・申告価格をまとめてコピーし、Claude Coworkで日本郵便「国際郵便マイページ」への入力を自動化可能
- **商品集計**: これから梱包する分の商品別合計数量。仕入れ・在庫確認に
- **注文コピー機能**: お客様が注文内容をワンタップでコピーしてLINEに貼れる
- **メール通知**: 新規注文をメールで受け取れる(設定シートで有効化)
- **管理者代理入力**: チャットで受けた注文を管理者がフォームから代理登録(誰が入力したか記録されます)

## Claude Coworkで発送ラベル入力を自動化する(任意)

デスクトップアプリの **Claude Cowork** を使うと、日本郵便
「国際郵便マイページサービス」での台湾宛発送ラベル作成を自動化できます。手順:

1. このリポジトリの `cowork-skill/japanpost-intl-entry` フォルダをCoworkのスキルとして
   追加する(詳細は `cowork-skill/README.md`)
2. 管理者ページ「発送」タブで「📋 発送ラベル入力データをコピー」
3. Coworkに貼り付けて「**発送ラベル作って**」と依頼
4. Coworkがブラウザで国際郵便マイページを開き、宛先(台湾住所・氏名の英語表記変換含む)・
   内容品(英語変換含む)・重量・申告価格を自動入力
5. **登録前に必ず内容確認を求めてくる**ので、確認して承認 → ラベルを印刷し、
   追跡番号(例: EM123456789JP)を管理者ページに入力して「発送済にする」

※ ログインは自分で行います(CoworkにID・パスワードは渡しません)。
※ ラベル登録の確定は必ず人間の承認後に行われる安全設計です。
※ 台湾宛の禁制品(食品などの規制を含む)は日本郵便・台湾側の最新情報をご確認ください。

## 商品やデータを変更したいとき

- **商品の追加・価格変更**: 「商品マスター」シートを編集するだけ。即座にフォームへ反映
- **売り切れ**: 「有効」列を `無効` にすればフォームから消えます
- **注文の修正**: 「注文一覧」シートを直接編集してOK
- **プログラムを更新したとき**: 「デプロイ → デプロイを管理 → 編集(鉛筆) → バージョン: 新バージョン → デプロイ」でURLを変えずに更新できます

## よくあるトラブル

| 症状 | 対処 |
|---|---|
| フォームに商品が出ない | 商品マスターの「有効」列を確認。商品IDと商品名が両方入っているか確認 |
| 管理者ページが開けない | URLの `key=` が「設定」シートの管理者キーと一致しているか確認 |
| 「シートが見つかりません」エラー | メニュー「注文フォーム → 初期セットアップ」を実行 |
| お客様が開くとGoogleログインを求められる | デプロイ設定の「アクセスできるユーザー」を「全員」にして再デプロイ |
