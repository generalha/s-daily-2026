# LINE注文フォーム セットアップ手順

LINEオープンチャット/LINEでの注文受付を、URLひとつで使える注文フォームに置き換えるシステムです。
データはすべてGoogleスプレッドシートに保存されるので、いつでも見返せて消えません。

- **お客様**: URLを開く → 商品と数量を選ぶ → 送信 → 振込先(台湾郵便局)が表示される
- **管理者**: 管理者ページで注文一覧・梱包リスト・商品集計を確認、ステータス管理
- **費用**: 無料(Googleアカウントのみ必要)

---

## 1. スプレッドシートを作成する

1. [Google スプレッドシート](https://sheets.google.com) で新規スプレッドシートを作成
   (名前は自由。例:「注文管理2026」)
2. メニュー「**拡張機能 → Apps Script**」を開く

## 2. プログラムを貼り付ける

Apps Script エディタで以下の3ファイルを作成します。

| エディタ上のファイル名 | 貼り付ける内容 |
|---|---|
| `コード.gs` (最初からある) | `gas/Code.gs` の中身をすべて貼り付け(元の内容は削除) |
| `Form.html` (＋ → HTML で新規作成) | `gas/Form.html` の中身 |
| `Admin.html` (＋ → HTML で新規作成) | `gas/Admin.html` の中身 |

※ HTMLファイル名は大文字小文字も含めて **Form** / **Admin** と正確に付けてください。

保存(Ctrl+S / ⌘S)します。

## 3. 初期セットアップを実行する

1. スプレッドシートのタブに戻り、**ページを再読み込み**する
2. メニューに「**注文フォーム**」が増えているので、「**初期セットアップ(シート作成)**」をクリック
3. 初回は権限の承認画面が出ます:
   「権限を確認」→ 自分のアカウントを選択 → 「詳細」→「(プロジェクト名)に移動」→「許可」
4. もう一度「初期セットアップ」を実行すると、3つのシートが作成されます:
   - **商品マスター** — 販売する商品と台湾元価格
   - **注文一覧** — 注文が自動で記録される
   - **設定** — 振込先口座・管理者キーなど

## 4. 設定を入力する

### 「設定」シート

| 設定キー | 入力する内容 |
|---|---|
| 振込先_銀行名 | そのままでOK(台湾 中華郵政) |
| 振込先_郵局代号 | `700`(中華郵政の局番) |
| 振込先_口座番号 | **ご自身の郵便局口座番号**(例: `0000000-0000000`) |
| 振込先_口座名義 | 口座名義人のお名前 |
| 振込メモ | 注文完了画面に出す案内文(例:「振込後、チャットでお知らせください」) |
| 管理者キー | 自動生成済み。管理者ページURLに使う秘密の文字列(変更可) |
| 通知メール | 新規注文をメールで受け取りたい場合にアドレスを入力(不要なら空欄) |

### 「商品マスター」シート

| 列 | 内容 |
|---|---|
| 商品ID | 重複しないID(例: P001, P002…) |
| 商品名 | フォームに表示される商品名 |
| 価格(元) | **台湾元の価格**。注文フォームに自動表示されます |
| 表示順 | 小さい数字ほど上に表示 |
| 有効 | `有効` で表示 / `無効` で非表示(売り切れ時など) |

サンプル商品2件が入っているので、実際の商品に書き換えてください。

## 5. ウェブアプリとして公開(デプロイ)する

1. Apps Script エディタ右上の「**デプロイ → 新しいデプロイ**」
2. 歯車アイコン → 種類「**ウェブアプリ**」を選択
3. 設定:
   - 説明: 任意(例:「注文フォーム v1」)
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**(お客様がGoogleログインなしで使うために必須)
4. 「デプロイ」→ 発行された **ウェブアプリURL** をコピー

### 発行されるURL

| 用途 | URL |
|---|---|
| お客様用フォーム | `(ウェブアプリURL)` |
| 管理者ページ | `(ウェブアプリURL)?page=admin&key=(管理者キー)` |
| 管理者による代理入力フォーム | `(ウェブアプリURL)?page=staff&key=(管理者キー)` |

管理者キーは「設定」シートの値です。**管理者用URLはお客様に共有しないでください。**

## 6. LINEでお客様に案内する

1. お客様用フォームのURLをコピー
2. URLが長いので、LINEオープンチャットの「**ノート**」や「**アナウンス(ピン留め)**」に貼るのがおすすめ
3. 必要なら短縮URLサービスで短くしてもOK

案内文の例:

> 📢 ご注文はこちらのフォームからお願いします!
> (URL)
> 商品と数量を選ぶだけでOK。送信すると振込先も表示されます。

## 日々の運用フロー

1. **お客様がフォームから注文** → 「注文一覧」シートに自動記録、完了画面に振込先を表示
2. お客様が「注文内容をコピー」ボタンでLINEに貼り付け → チャット上でも確認できる
3. **入金を確認したら** → 管理者ページで該当注文を「入金確認済」に変更
4. **梱包するとき** → 管理者ページの「梱包リスト」タブを開く
   (入金確認済の注文がお客様ごとに大きな文字で表示され、チェックしながら梱包できます)
5. 梱包が終わったら「梱包済にする」ボタン → お渡し後に「受渡済」へ

### ステータスの意味

| ステータス | 意味 |
|---|---|
| 未対応 | 注文直後(入金待ち) |
| 入金確認済 | 振込を確認した → 梱包リストに表示される |
| 梱包済 | 梱包が完了した |
| 受渡済 | お客様にお渡し完了 |
| キャンセル | キャンセルされた注文 |

## 便利機能まとめ

- **台湾元の自動表示**: 商品マスターに登録済みの商品は、注文時に価格と合計が自動表示
- **自由入力商品**: マスターにない商品もお客様が名前入りで注文可能(価格は後で「注文一覧」シートの単価・小計欄に直接記入すればOK)
- **注文番号の自動採番**: `20260811-001` 形式で毎日リセット
- **梱包リスト**: 入金確認済の注文だけをお客様単位で表示。梱包ミス防止に
- **商品集計**: これから梱包する分の商品別合計数量。仕入れ・在庫確認に
- **注文コピー機能**: お客様が注文内容をワンタップでコピーしてLINEに貼れる
- **メール通知**: 新規注文をメールで受け取れる(設定シートで有効化)
- **管理者代理入力**: チャットで受けた注文を管理者がフォームから代理登録(誰が入力したか記録されます)

## 商品やデータを変更したいとき

- **商品の追加・価格変更**: 「商品マスター」シートを編集するだけ。即座にフォームへ反映
- **売り切れ**: 「有効」列を `無効` にすればフォームから消えます
- **注文の修正**: 「注文一覧」シートを直接編集してOK
- **プログラムを更新したとき**: 「デプロイ → デプロイを管理 → 編集(鉛筆) → バージョン: 新バージョン → デプロイ」でURLを変えずに更新できます

## よくあるトラブル

| 症状 | 対処 |
|---|---|
| フォームに商品が出ない | 商品マスターの「有効」列を確認。商品IDと商品名が両方入っているか確認 |
| 管理者ページが開けない | URLの `key=` が「設定」シートの管理者キーと一致しているか確認 |
| 「シートが見つかりません」エラー | メニュー「注文フォーム → 初期セットアップ」を実行 |
| お客様が開くとGoogleログインを求められる | デプロイ設定の「アクセスできるユーザー」を「全員」にして再デプロイ |
