# EZPost発送入力スキル

注文管理システム(管理者ページの発送タブ)からコピーした「EZPost入力データ」をもとに、
中華郵政のEZPostサイトで国際郵便の交寄(発送)フォームを入力する。

## 入力データの形式

ユーザーは次の形式のテキストを貼り付けてくる(管理者ページの
「📋 EZPost入力データをコピー」ボタンで生成されたもの):

```
【EZPost入力データ】
注文番号: 20260811-001
配送方法: EMS
重量(g): 850
お届け先氏名: 山田 花子
お届け先住所: 〒123-4567 東京都○○区○○ 1-2-3
お届け先電話: 090-1234-5678
内容品: ドライマンゴー x2, パイナップルケーキ x1
申告価格(元): 690
```

複数件が連続して貼り付けられることもある(【EZPost入力データ】ごとに1件)。
データが貼り付けられていない場合は、管理者ページの発送タブからコピーして
貼り付けるよう依頼する。

## 手順

1. **データの確認**: 貼り付けられたデータを解析し、件数と内容を箇条書きで復唱する。
   氏名・住所・重量など必須項目が欠けている場合は、先にユーザーに確認する。

2. **EZPostを開く**: ブラウザで https://ezpost.post.gov.tw/ を開く。
   未ログインの場合は**ユーザー自身にログインしてもらう**(ID・パスワードは扱わない)。
   ログイン完了の連絡を待ってから次へ進む。

3. **交寄種別の選択**: 「配送方法」に応じて選ぶ。
   - `EMS` → 国際快捷(EMS)
   - `国際小包(航空)` → 國際包裹(航空)
   - `国際小包(船便)` → 國際包裹(水陸)

4. **宛先(日本)の入力**:
   - 国: 日本 (Japan)
   - 氏名: データの「お届け先氏名」。ローマ字欄が必須の場合はヘボン式に変換して入力し、変換結果を報告する
   - 住所: データの「お届け先住所」。郵便番号・都道府県以下を項目に合わせて分割する
   - 電話: データの「お届け先電話」

5. **内容品の入力**: 「内容品」の各品目を入力する。英語名が必須の場合は
   一般的な英語表記に変換する(例: ドライマンゴー → Dried Mango)。
   数量・単価も入力し、申告総額が「申告価格(元)」と一致するようにする。
   品目区分は原則「Gift」または「Merchandise」のうち実態に合うものを選ぶ。

6. **重量の入力**: 「重量(g)」を入力する(サイトがkg単位ならkgに換算)。

7. **送信前の確認(必須)**: 入力内容のスクリーンショットまたは要約を提示し、
   **ユーザーの承認を得るまで絶対に送信(確定)ボタンを押さない**。

8. **送信後**: 発行された郵便物番号(追跡番号、例: EE123456789TW)を控えて報告し、
   管理者ページの発送タブで該当注文の「追跡番号」欄に入力して
   「✈️ 発送済にする」を押すよう案内する。
   (管理者ページのURLを教えてもらっていれば、代わりにブラウザで開いて入力してもよい。
   その場合も「発送済にする」を押す前にユーザーの確認を取る)

## 注意事項

- サイトの画面構成が本スキルの想定と異なる場合は、無理に操作せず現状を報告して指示を仰ぐ
- 宛先などの個人情報をEZPostと管理者ページ以外のサイトに入力・送信しない
- 料金や規約の最終確認はユーザーの責任で行ってもらう(発送手続きの確定は必ず人間の承認後)
- 複数件ある場合は1件ずつ処理し、各件の送信前に確認を取る
