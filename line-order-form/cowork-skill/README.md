# Claude Cowork用 発送ラベル自動入力スキル(日本郵便・台湾宛)

`japanpost-intl-entry/` は、デスクトップアプリ **Claude Cowork** に追加して使うスキルです。
管理者ページの発送タブでコピーした「発送ラベル入力データ」を貼り付けて
「発送ラベル作って」と頼むと、日本郵便の**国際郵便マイページサービス**での
台湾宛EMS・国際小包の発送ラベル作成を自動化できます。

## インストール方法

1. `japanpost-intl-entry` フォルダ(中に `SKILL.md`)をパソコンにコピーする
2. Claude Cowork の設定からスキル(Skills)として `japanpost-intl-entry` フォルダを追加する
   - スキル追加のUIがない場合は、`~/.claude/skills/japanpost-intl-entry/SKILL.md` に
     配置すると Claude Code / Cowork から利用できます
3. Cowork のチャットで「発送ラベル作って」と入力し、続けて
   管理者ページでコピーした「発送ラベル入力データ」を貼り付ける

## 使い方の流れ

1. 管理者ページ「発送」タブ → 発送待ちの注文で「📋 発送ラベル入力データをコピー」
2. Cowork に貼り付けて「発送ラベル作って」
3. Cowork がブラウザで https://www.int-mypage.post.japanpost.jp/ を開く(ログインは自分で行う)
4. 宛先(台湾住所・氏名の英語表記変換)・内容品(英語変換)・重量・申告価格が自動入力される
5. **登録前に必ず内容を確認して承認**(承認するまで登録されません)
6. ラベルを印刷し、追跡番号(例: EM123456789JP)を管理者ページの「追跡番号」欄に入力
   → 「✈️ 発送済にする」

## 安全設計

- ログインID・パスワードはCoworkに渡さない(ログインは人間が行う)
- ラベル登録の確定は必ず人間の承認後
- サイトの画面が変わった場合は自動操作を中断して報告する
