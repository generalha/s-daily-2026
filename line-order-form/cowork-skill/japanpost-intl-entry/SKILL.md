# 日本郵便 国際郵便発送ラベル入力スキル(台湾宛)

注文管理システム(管理者ページの発送タブ)からコピーした「発送ラベル入力データ」をもとに、
日本郵便の**国際郵便マイページサービス**で台湾宛EMS・国際小包の発送ラベルを作成する。

## 入力データの形式

ユーザーは次の形式のテキストを貼り付けてくる(管理者ページの
「📋 発送ラベル入力データをコピー」ボタンで生成されたもの):

```
【発送ラベル入力データ】
注文番号: 20260811-001
配送方法: EMS
重量(g): 850
お届け先氏名: 王 小明
お届け先住所: 106 台北市大安區○○路○段1號5樓
お届け先電話: 0912-345-678
内容品: ドライフルーツ x2, お菓子 x1
申告価格(元): 690
```

複数件が連続して貼り付けられることもある(【発送ラベル入力データ】ごとに1件)。
データが貼り付けられていない場合は、管理者ページの発送タブからコピーして
貼り付けるよう依頼する。

## 手順

1. **データの確認**: 貼り付けられたデータを解析し、件数と内容を箇条書きで復唱する。
   氏名・住所・重量など必須項目が欠けている場合は、先にユーザーに確認する。

2. **国際郵便マイページを開く**: ブラウザで
   https://www.int-mypage.post.japanpost.jp/ を開く。
   未ログインの場合は**ユーザー自身にログインしてもらう**(ID・パスワードは扱わない)。
   ログイン完了の連絡を待ってから次へ進む。

3. **発送ラベルの新規作成**: 「配送方法」に応じて郵便種別を選ぶ。
   - `EMS` → EMS(物品)
   - `国際小包(航空)` → 国際小包・航空便
   - `国際小包(船便)` → 国際小包・船便
   - お届け先の国は **台湾(Taiwan)**

4. **宛先(台湾)の入力**: サイトはローマ字(英語表記)での入力が求められる。
   - 氏名: 中国語名はピンイン等のローマ字表記に変換して入力し、変換結果を報告する
     (例: 王 小明 → WANG XIAO MING)。データに英語表記の指定があればそれを優先
   - 住所: 台湾住所を英語表記に変換して入力し、変換結果を報告する
     (例: 106 台北市大安區○○路○段1號5樓 → 5F., No.1, Sec.○, ○○ Rd., Da'an Dist., Taipei City 106, Taiwan)
   - 電話: データの「お届け先電話」をそのまま入力

5. **内容品の入力**: 「内容品」の各品目を英語に変換して入力する
   (例: ドライフルーツ → Dried Fruits)。数量・単価も入力し、申告総額が
   「申告価格(元)」に相当する金額になるようにする(サイトの通貨指定に合わせて
   円換算が必要な場合は換算内容を報告する)。
   内容品種別は実態に合わせて「販売品(Merchandise)」等を選ぶ。

6. **重量の入力**: 「重量(g)」を入力する(サイトがkg単位ならkgに換算)。

7. **送信前の確認(必須)**: 入力内容のスクリーンショットまたは要約を提示し、
   **ユーザーの承認を得るまで絶対に登録(確定)ボタンを押さない**。

8. **登録後**: ラベルを印刷してもらい、発行された追跡番号
   (例: EM123456789JP)を控えて報告する。管理者ページの発送タブで該当注文の
   「追跡番号」欄に入力して「✈️ 発送済にする」を押すよう案内する。
   (管理者ページのURLを教えてもらっていれば、代わりにブラウザで開いて入力してもよい。
   その場合も「発送済にする」を押す前にユーザーの確認を取る)

## 注意事項

- サイトの画面構成が本スキルの想定と異なる場合は、無理に操作せず現状を報告して指示を仰ぐ
- 宛先などの個人情報を国際郵便マイページと管理者ページ以外のサイトに入力・送信しない
- 台湾宛の発送条件・禁制品(食品等の輸入規制を含む)・料金の最終確認はユーザーの責任で
  行ってもらう(ラベル登録の確定は必ず人間の承認後)
- 複数件ある場合は1件ずつ処理し、各件の登録前に確認を取る
