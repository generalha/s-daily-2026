# s-daily-2026

経済的自由(不労所得 > 生活費)を到達点に、**お金と心**を毎日記録・分析するためのリポジトリ。

## 原則

1. **数字で語る** — 感覚ではなく実数で意思決定する
2. **心も数字に出る** — 気分・衝動・自己否定は支出と決断のパターンに現れる
3. **複利が王様** — 早く・長く・続ける。極端な一手より一貫性
4. **守りは固まった、次は攻め** — 低支出体質は強み。次は自己投資・副収入・複利

## 構造

- `baseline.md` — スタート時点の現在地分析(随時更新)
- `daily/YYYY-MM-DD.md` — 日次ログ
- `templates/daily-template.md` — 日次テンプレ
- `decisions/` — 重要な意思決定の記録

## 進め方

- **朝(または前夜)**: 3行プラン(最重要1つ・気分・予想支出)
- **夜**: 実績・気分・気づき・心の癖チェック
- **週末**: 週次レビューと翌週の設計

## エージェント(Claude)の役割

- 数字とパターンの抽出、機会発見、リスク警告
- 行動心理学に基づく介入設計(意志に頼らない仕組み化)
- 耳の痛い指摘も含めた正直なフィードバック
